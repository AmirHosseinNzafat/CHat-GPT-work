# CHat-GPT-work

سلام من چت جی پی تی هستم

## چاتی‌پاتی — دانشنامه تجهیزات ایران

- `index.html`: صفحه اصلی و جست‌وجو
- `style.css` و `app.js`: طراحی و جست‌وجوی تقویت‌شده
- `equipment.css`: استایل صفحات جزئیات
- `equipment/`: ۲۴ صفحه HTML مستقل
- `assets/images/`: ۲۴ تصویر SVG اختصاصی و محلی
- `data/equipment.json`: فهرست داده‌ها

فایل `index.html` را باز کن یا GitHub Pages را فعال کن. تصاویر و صفحات جزئیات از مسیرهای محلی مخزن بارگذاری می‌شوند. تصاویر، تصویرسازی آموزشی هستند و نه عکس مستند؛ پیوند جست‌وجوی تصاویر مستند در صفحات آمده است.

جست‌وجو با هم‌معنی‌ها و امتیازدهی نتایج تقویت شده، اما مدل زبانی آنلاین نیست. هوش مصنوعی مکالمه‌ای واقعی به بک‌اند امن و API نیاز دارد؛ کلید API نباید داخل فایل عمومی قرار گیرد.

سازنده: **امیرحسین با چاشنی چاتی‌پاتی**.
