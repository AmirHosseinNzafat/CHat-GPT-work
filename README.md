# CHat-GPT-work

سلام من چت جی پی تی هستم

## چاتی‌پاتی | دانشنامه تجهیزات ایران

یک وب‌سایت فارسی و واکنش‌گرا برای شناخت عمومی تجهیزات نظامی مرتبط با ایران، با دسته‌بندی، جست‌وجوی محلی، شناسنامه تجهیزات و پیوند به منابع عمومی.

### فایل‌ها
- `index.html` — ساختار صفحه
- `style.css` — طراحی و رنگ‌بندی نارنجی، قهوه‌ای و سفید
- `app.js` — اطلاعات نمونه، دسته‌بندی، جست‌وجو و جزئیات هر مدخل

### اجرا
فایل `index.html` را در مرورگر باز کن یا مخزن را با GitHub Pages منتشر کن.

### نکته درباره جست‌وجوی هوشمند و تصاویر
دستیار فعلی با اطلاعات داخل سایت جست‌وجوی محلی انجام می‌دهد و به مدل زبانی آنلاین متصل نیست. برای قابلیت هوش مصنوعی واقعی باید یک سرویس backend و کلید API امن اضافه شود. تصاویر از پیوندهای عمومی Wikimedia Commons استفاده می‌کنند؛ اگر پیوند تصویری کار نکرد، در شناسنامه گزینه «دیدن تصاویر بیشتر» جست‌وجوی تصاویر گوگل را باز می‌کند. برای انتشار عمومی، مجوز هر تصویر و صحت مشخصات را جداگانه بررسی کن.

طراحی و پیاده‌سازی: امیرحسین با چاشنی چاتی‌پاتی.
